# Диагностика

- **Данные исчезли после очистки сайта:** восстановите внешний JSON. Локальные snapshots удаляются вместе с данными сайта.
- **Storage не Persistent:** разрешите браузеру постоянное хранилище; статус и quota показаны в Settings → Data.
- **Import отклонён:** исправьте первые JSON paths из сообщения. Текущий workspace не меняется.
- **Красные связи:** Free move нарушил FS. Используйте «Исправить расписание» либо измените lag/dates.
- **Cascade остановлен:** successor locked. Отмените, выполните Free либо разблокируйте stage.
- **PNG слишком большой:** выберите viewport, один квартал или меньше эпиков; для полного плана используйте print/PDF.
- **Интерфейс закрыт предупреждением:** редактируемая ширина начинается с 1280 px.
- **Recovery overlay:** выберите последний корректный backup либо безопасный сброс. Перед сбросом сохраняется диагностический snapshot.

Диагностика не отправляется автоматически. Browser console и Playwright traces используются только локально.
