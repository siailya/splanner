# Backup и восстановление

Ручному snapshot пользователь задаёт имя. Автоматические snapshots создаются ежедневно при изменениях и перед import, массовым удалением, календарём и restore. Сохраняются последние 10 копий или до 20 МБ суммарно.

В Settings → Data видны имя/причина, дата, размер и число сущностей. «Просмотр» показывает состав payload до подтверждения restore:

1. валидирует payload в памяти;
2. создаёт `before_restore` текущего состояния;
3. атомарно заменяет tables;
4. при ошибке возвращает прежний workspace.

Повреждённый snapshot не изменяет данные. Кнопка download превращает snapshot в обычный workspace JSON. Backup находится в том же browser storage, поэтому не заменяет внешний JSON-файл.
